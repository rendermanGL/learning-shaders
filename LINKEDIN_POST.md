## Draft

I have been getting back to building small, fun projects as a way to learn.

This one is a shader learning playground: a tiny browser-based shader engine that breaks down how fragment shaders work, from UV coordinates to distance fields, color mixing, and animated sine waves.

The part I enjoyed most was using AI less like a shortcut and more like a learning partner. I would ask questions, build the thing, inspect what broke, then keep shaping the tool until the math started to feel visual instead of abstract.

The project now has two pieces:

- A live shader walkthrough that shows how pixels are built up in stages
- A math lab that visualizes concepts like `vec2`, `length()`, `mix()`, and `sin()`

It is not meant to be a giant polished product. It is one of those little projects that helps you remember why building things is fun: you start with curiosity, make something visible, and learn through the process.

AI made the loop faster, but the learning still came from asking better questions, testing the page, debugging the weird bits, and connecting the code back to the concept.

More of this kind of building, please.
